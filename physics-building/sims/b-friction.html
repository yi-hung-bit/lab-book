摩擦力：從靜摩擦到動摩擦

用水平力 F 拉桌上的木塊，F 從零慢慢增加。木塊不動時，靜摩擦力剛好等於 F；F 超過最大靜摩擦力，木塊開始滑動，摩擦力掉到比較小的動摩擦力，多出來的力讓木塊加速：F − fk = ma。

想一想

木塊已經在滑動後，把 F 調回 75 N（比 80 N 小、比 70 N 大），木塊會停下來嗎？

不會。滑動時摩擦力是 fk = 70 N，F = 75 N 仍大於 70 N，木塊繼續加速（a = 0.5 m/s²）。fs,max 只決定「能不能開始動」。

滑動中把 F 調成 60 N 會怎樣？調成 0 呢？

F < fk，合力向後，木塊減速：F = 60 N 時 a = (60 − 70)/10 = −1 m/s²；F = 0 時 a = −7 m/s²。停下來以後摩擦力又變回靜摩擦，等於 F。

同樣的桌面，木塊質量加倍為 20 kg，最少要多大的 F 才拉得動？

正向力加倍，最大靜摩擦力也加倍：16 kgw = 160 N。這就是越重的東西越難拉動。
教學提示：「靜摩擦力」不是固定值，而是「需要多少就出多少」，最多到 fs,max；所以靜止時 f = F，拉力是多少摩擦力就是多少。一旦滑動，摩擦力大致固定為 fk，通常 fk < fs,max，所以「拉動的瞬間最吃力，動了以後比較輕鬆」。1 kgw 是 1 kg 物體受的重力，本頁取 g = 10 m/s²，1 kgw = 10 N。
