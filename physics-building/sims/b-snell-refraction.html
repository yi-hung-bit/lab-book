光的折射與司乃耳定律

光斜斜地從一種介質射進另一種介質，在界面上一部分反射、一部分折射。以入射點 O 為圓心畫半徑 R = 10 cm 的輔助圓，入射線、折射線和圓的交點到法線的距離 x₁、x₂，不管入射角多大，比值 x₁ / x₂ 都是定值，這就是司乃耳定律；光從真空射入介質時，這個定值就是介質的折射率 n = c / v。

範例 4-8 司乃耳定律空氣 → 玻璃，a = 6 cm、b = 4 cm

(1) 玻璃對空氣的折射率？(2) θ₁ 減小時 θ₂ 怎麼變？(3) a = 3 cm 時 b = ？

(1) n = a / b = 6 / 4 = 1.50。(2) θ₁ 減小，θ₂ 也減小。(3) a / b = a′ / b′ ⇒ 6 / 4 = 3 / b′ ⇒ b′ = 2 cm。按上面兩個按鈕，對照圖中的 x₁、x₂ 讀數。
範例 4-9 潛水員的光由水中以 45° 射入甲、乙、丙

(1) 射入甲時折射角幾度？(2) 光在甲、乙、丙中的速率快慢順序？

(1) 折射角是折射線和法線的夾角：90° − 60° = 30°（比 45° 小，偏向法線）。(2) 甲偏向法線 ⇒ 甲比水慢；乙不偏折 ⇒ 和水一樣快；丙偏離法線 ⇒ 比水快。所以 丙 ＞ 乙 ＞ 甲。用 n₁x₁ = n₂x₂ 估算：甲 n ≈ 1.88、乙 n = 1.33、丙 n ≈ 1.09。

想一想

光垂直射入水中（θ₁ = 0°）會偏折嗎？光速會變嗎？

不偏折（x₁ = x₂ = 0，θ₂ = 0°），但光進入水中後速率仍然變成 c / 1.33，波前間距變短。折射的根本原因是光速改變。

光從玻璃射向空氣，入射角越來越大，會發生什麼事？

偏離法線，θ₂ 比 θ₁ 大。θ₁ 大到某個角度（玻璃約 41.8°）時 x₂ 就要等於 R，再大就沒有折射光，光全部反射回玻璃，這叫全反射，選修物理三會詳細學。

潛水員在水中抬頭看岸上的人，那個人看起來比實際高還是矮？

光由空氣（光疏）進入水（光密）時偏向法線，潛水員順著光線往回看，覺得光從更高的地方來，所以岸上的人看起來比實際高。
教學提示
1. 先讓學生在同一組介質下記錄 3～4 個入射角，自己發現 x₁ / x₂ 是定值，再命名為折射率。
2. 基礎物理用輔助圓的 x₁、x₂ 描述司乃耳定律；x₁ = R sin θ₁ 留待選修物理三再用三角函數表示。
3. 判斷偏折口訣：光疏 → 光密偏向法線，光密 → 光疏偏離法線；光密指 n 大、光速慢，不是質量密度大。
4. 用惠更斯子波說明波前為什麼轉折，可以搭配 229 教室「惠更斯原理與折射定律」。
