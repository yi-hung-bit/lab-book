Wilberforce 擺：拍現象與耦合參數量測

由垂直振動 z(t) 的拍現象求耦合係數 ε 與自然角頻率 ω₀

系統參數

m₀ = 0.50 kg，I₀ = 2.0×10⁻⁴ kg·m²（僅影響 θ 的幅度，不影響頻率）。

能量分配

振動
轉動

能量在兩種運動間來回交換，交換一次所需時間即為拍的節點間隔 2π/(ω₊−ω₋)。

裝置

即時曲線（最近 6 秒）

z(t)（cm）　θ(t)（度）

z(t) 的 0–5 秒完整波形（對照題目圖 14）

精確解　近似包絡 ±z₀|cos(εω₀t/2)|（θ(0)=0、γ=0 時成立）

理論推導

令 z̃ = √m₀ z、θ̃ = √I₀ θ，動能與位能化為

T = ½(ż̃² + θ̃̇²)，　V = ½ω₀²(z̃² + 2ε z̃θ̃ + θ̃²)

取常態座標 q± = (z̃ ± θ̃)/√2，兩者各自做簡諧振動，角頻率為

ω± = ω₀√(1 ± ε) ≈ ω₀(1 ± ε/2)

初始條件 z̃(0) = z̃₀、θ̃(0) = 0、靜止釋放，得

z̃(t) = ½z̃₀(cos ω₊t + cos ω₋t) = z̃₀ cos(ω̄t) cos(Δt/2)，　ω̄ = (ω₊+ω₋)/2，Δ = ω₊−ω₋

因此量測兩個量即可求兩個未知數：

節點間隔 Tb = 2π/Δ，　載波週期 Tc = 2π/ω̄
精確反解：ω₀ = √(ω̄² + Δ²/4)，　ε = ω̄Δ / (ω̄² + Δ²/4)
ε ≪ 1 近似：ω₀ ≈ ω̄，　ε ≈ Δ/ω̄ = Tc/Tb

題目圖 14：節點約在 t = 1、3 s（Tb = 2 s），載波週期約 0.2 s，故 ω₀ = 10π ≈ 31.4 rad/s、ε = 0.2/2 = 0.1。
注意：包絡通過節點時載波相位翻轉 180°，所以量載波週期時要在同一個拍之內計數，不能跨越節點。實驗頁改用「上升零點」而非波峰，因為包絡斜率會讓波峰位置偏移。

實驗設定

每次「新實驗」都會隨機產生隱藏的 ε、ω₀、阻尼與釋放時的微小扭轉。z₀ = 2.00 cm。

尚未建立實驗

感測器雜訊標準差 0.02 cm，解析度 0.01 cm；節點標記的時間取到 0.01 s，內插零點取到 0.001 s。

裝置

z(t) 記錄

點擊曲線的動作：
移動滑鼠可讀取 t 與 z

建議流程：先用「全部」或 10 s 視窗找出所有節點（振幅最小處），點擊標記；再放大到 1–2 s，在同一個拍內逐一點擊 z 由負變正的零點，並只取拍中央的一半範圍（避開節點前後各 1/4 個節點間隔）。程式會找出點擊處附近的上升零點，並在相鄰兩個取樣點間線性內插求時刻。
為什麼不用波峰？z = z₀cos(ω̄t)cos(Δt/2) 的極大值會被包絡的斜率拉偏：拍的前半段波峰延後、後半段提前，使波峰間隔系統性偏短（ε = 0.1 時約 0.3%）；零點則恰好落在載波零點上，沒有這個偏差。

驗證

完成分析後再揭曉隱藏參數。偏差以「幾個標準差」表示：|偏差| < 2σ 可視為與真值一致。
