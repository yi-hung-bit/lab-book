磁力線與地磁

磁鐵周圍存在磁場。法拉第在磁棒附近灑下鐵粉，看到特定的分布，於是提出磁力線的觀念：磁力線的切線方向就是磁場方向，可以用小磁針測量（磁針 N 極所指的方向）；磁力線越密，磁場越強。磁棒外部的磁力線由 N 極出發到 S 極，內部由 S 極到 N 極，是一條條封閉曲線，彼此不相交。

說明
地理北極附近是地磁的 S 極，所以指南針的 N 極被吸引、大致指向北方；地理南極附近是地磁的 N 極。磁軸與自轉軸不重合，所以指南針指的「磁北」和真正的北方差一個角度（磁偏角），而且地磁的磁極位置會慢慢移動。

③ 想一想 課本旁欄的問題，先猜再看說明

磁力線的方向必定由 N 極出發到 S 極嗎？

只有在磁棒外部是由 N 到 S；在磁棒內部由 S 到 N。磁力線是沒有起點也沒有終點的封閉曲線（和電力線由正電荷出發、終止於負電荷不同）。把磁棒切成兩半，每一半仍各有 N、S 兩極。

若將一個小磁鐵在磁場中釋放，它運動的軌跡就是某一條磁力線嗎？

不是。磁力線只告訴我們「小磁針會轉向哪個方向」：小磁針受到力矩，轉到 N 極沿著磁力線的切線方向。小磁鐵兩極受力方向相反，在不均勻的磁場中合力通常指向磁場較強處（被吸向磁極），而且運動還有慣性，所以軌跡一般不會沿著磁力線走。

兩根磁棒同極相對與異極相對，磁力線看起來有什麼不同？

異極相對：磁力線從一根的 N 極直接連到另一根的 S 極，像被拉緊的橡皮筋，兩磁棒互相吸引。同極相對：兩邊的磁力線互相「推開」、不相交，中間有一點磁場為零（鐵粉幾乎不排列），兩磁棒互相排斥。

在台灣把指南針放平，N 極指向北方。如果把指南針立起來（可以上下轉），N 極會朝上還是朝下？

北半球的地磁磁力線斜斜地進入地面（往地磁 S 極去），所以 N 極會朝下傾斜；越靠近磁極越陡，在磁極上方幾乎垂直。南半球則 N 極朝上傾斜，在磁赤道附近是水平的。
說明：① 把磁棒看成沿長邊的均勻磁化（等效為兩側相反方向的面電流），在平面上計算磁場，再從磁棒中央截面等間隔出發描出磁力線，所以線的疏密反映磁場強弱，而且每條線都是封閉的；兩根磁棒互相吸引或排斥由磁棒 2 所受的合力判斷。② 地磁用地心的磁偶極近似（真實地磁較不規則）；磁傾角由該處磁場方向與當地水平面的夾角算出，偶極近似下地表滿足 tan I = 2 tan λ（λ 為磁緯）。參考：基礎物理 第 3 章 3-3 基本交互作用（p.72–73 圖 3-13）。
