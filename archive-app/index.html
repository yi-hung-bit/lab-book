這支檔案怎麼用

這是個人用的檔案室，網址上只有程式本身，你登記的卷宗不會上傳到任何伺服器。
  1. 裝成 App：Android／電腦版 Chrome 按上方「安裝成 App」（或瀏覽器選單的「安裝應用程式／加到主畫面」）；iPhone 用 Safari 的「分享 → 加入主畫面」。裝好後沒網路也能開。
  2. 資料存在這台裝置的這個 App 裡：手機和電腦各有一份，不會自動同步。要搬資料或備份，用「匯出目錄」存成 JSON，到另一台「匯入目錄」。
  3. 上傳的檔案本體只存在上傳那台裝置裡，匯出的 JSON 不含檔案本體；需要兩邊都看得到的檔案，建議放雲端硬碟、卷宗用「連結」方式登記（開啟時仍照雲端硬碟的權限）。
