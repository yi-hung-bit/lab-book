一、題目與器材對應

題目要求：利用所列器材，設計實驗以求出所在地的重力加速度 g。器材清單中同時出現棉線、底片塑膠盒、硬幣、45 cm 直尺、馬錶、量角器、1 mm 方格紙，這組合指向的標準解法是單擺法。

二、實驗設計原理

1. 小角度單擺週期

質點單擺在小角度（sin θ ≈ θ）下作簡諧運動：

T = 2π √( L / g )   ⟹   T2 = (4π2/g) · L

其中 L 是懸點到擺錘質心的距離。

2. 本實驗的關鍵困難：質心位置量不到

擺錘是「底片盒＋裡面的硬幣」，它的質心在盒內，無法用直尺直接量到。若硬把線長當成 L，會系統性低估 g。

解法：把有效擺長拆成「可量的線長 ℓ」加上「未知但固定的偏移 d」：

L = ℓ + d   ⟹   T2 = (4π2/g)·ℓ + (4π2/g)·d
以 ℓ 為橫軸、T² 為縱軸作圖，應得一直線：
・斜率 a = 4π²/g ⟹ g = 4π²/a（與未知的 d 完全無關！）
・截距 b = 4π²d/g = a·d ⟹ d = b/a，還能反推質心偏移，可與盒子幾何比對驗證。

這是本題「結果計算及作圖（25%）」的核心：必須用多組數據作線性迴歸取斜率，而不是單點代公式再平均。單點法無法消去 d，是有系統偏差的做法。

3. 為什麼要量 N 個週期

馬錶的主要誤差來自人的反應時間（約 0.1～0.3 s），且與週期數無關。量 N 個週期的總時間 t，取 T = t/N，則反應時間造成的週期誤差被縮小 N 倍：

σT = σt / N

4. 必須控制的系統誤差（本模擬均忠實重現）

  • 有限振幅效應：實際週期 T = T0[1 + θ0²/16 + 11θ0⁴/3072 + …]。θ0 = 20° 時 T 偏大約 0.76%，使 g 偏小約 1.5%。故須用量角器把釋放角控制在 10° 以內。
  • 擺錘不是質點：底片盒有自身轉動慣量，實際為物理擺，T = 2π√((L + k²/L)/g)，k² = Icm/m。擺長太短時這項會讓 T²–ℓ 圖在低端向上彎。
  • 直尺只有 45 cm：線長超過 45 cm 必須分段接量，誤差累積放大。
  • 棉線受力伸長：掛上約 80 g 擺錘後棉線會拉長千分之幾，使真實擺長略大於量到的長度。
  • 空氣阻力：振幅在計時期間持續衰減，使「平均振幅修正量」小於用初始角算出的值。

三、實驗步驟大綱

  1. 用小刀在底片盒蓋中央開一小孔，棉線穿過後以牙籤橫向卡住打結，放入硬幣並蓋緊。
  2. 衛生筷以透明膠帶固定於桌緣，使其水平突出，棉線繞筷上並固定，形成明確懸點。
  3. 以 45 cm 直尺量懸點到盒蓋上緣的線長 ℓ（測到 0.05 cm）。
  4. 以量角器設定釋放角 θ0 ≤ 10°，於同一平面內釋放，不得推送、不得有圓錐擺動。
  5. 放手同時按下馬錶，計時 N = 20 個完整週期的總時間 t，重複數次。
  6. 改變 ℓ（建議 6～8 組，從 20 cm 到 90 cm），重複步驟 3–5。
  7. 以方格紙作 T²–ℓ 圖，取最佳直線斜率 a，計算 g = 4π²/a，並由截距檢驗質心偏移。

組裝擺錘

C. 其他系統誤差的來源與處理

1. 直尺量程 45 cm 的接段誤差

線長超過 45 cm 就必須在棉線上做記號、分兩段量。每次「移尺對準」都引入一次獨立的對準誤差，且記號本身有寬度，容易造成單向偏差。可行的對策：把最長的線長控制在 45 cm 以內（但會縮短迴歸的橫軸跨度、放大斜率誤差），或接受接段誤差但增加重複次數。兩者互相衝突，須在作答中說明取捨。

2. 棉線受力伸長

掛上約 80 g 擺錘後棉線會伸長約 0.05%～0.15%。若在未掛擺錘時量線長，量到的會比實際擺動時的擺長短，使 g 被低估。正確作法是在擺錘已掛上、靜止下垂的狀態下量測（本模擬即採此設定，故此項系統誤差已大致被吸收，殘留量小於 0.05%）。

3. 擺錘不是質點（物理擺修正）

完整式為 T = 2π√((L + k²/L)/g)，其中 k² = Icm/m。週期的相對修正量約為 k²/(2L²)，隨擺長平方反比衰減。以本題的底片盒擺錘，硬幣放 6 枚以上時 k² ≈ 1.0–1.3 cm²（下表以 k² = 1.0 cm² 估算）：

線長 ℓ (cm)有效擺長 L (cm)週期修正量g 的偏差
15≈ 19+0.14 %−0.28 %
30≈ 34+0.043 %−0.086 %
60≈ 64+0.012 %−0.025 %
90≈ 94+0.006 %−0.011 %

因此這一項在本實驗中其實相當小——即使最短的 15 cm 也只有 0.14%，遠小於按錶反應時間造成的隨機誤差。但它是非線性的：它讓 T²–ℓ 圖在短擺長端略微向上彎，無法被直線的截距吸收。若你的數據點跨度很大而短擺長端出現系統性的正殘差，就是這一項在作用；把最短擺長提高到 25 cm 以上即可忽略。

注意此項與質心偏移 d 的性質完全不同：d 是線性的（整條線平移，被截距完全吸收，不影響斜率與 g）；k²/L 是非線性的（使線彎曲，會真的污染斜率）。這兩者常被混為一談，是本題討論欄的高階得分點。

4. 空氣阻力

阻力不直接改變小角度週期（修正量為 ζ² 量級，可忽略），但會讓振幅在計時期間持續衰減。因此實際的「平均有限振幅修正」小於用初始角 θ₀ 算出的值——本模擬中 A 項的理論曲線已計入此衰減。

5. 週期數的計數錯誤

最常見的人為失誤：把釋放瞬間數成「1」。正確作法是釋放瞬間數「0」，擺錘回到同側時才數「1」。此項在模擬中不重現，但實作時足以讓 g 差 5% 以上。

對應評分項目：(a) 原理 20%、(b) 步驟 20%、(c) 數據 10%、(d) 計算作圖 25%、(e) 結果討論 25%。

  • 是否以迴歸斜率求 g？必須明確寫出 g = 4π²/a，並說明此法可消去未知的質心偏移 d。
  • 是否利用截距？由 b/a 反推 d，並與底片盒幾何（盒高、硬幣位置）比對，是加分的自洽性檢驗。
  • 是否報告不確定度？應寫成 g = (值 ± 誤差) m/s²，誤差由迴歸斜率的標準誤差傳遞而來，而非只寫平均值。
  • 是否控制振幅？說明用量角器將 θ₀ 限制在 10° 內的理由，並給出有限振幅修正式。
  • 是否說明 N 的選擇？σT = σt/N，故取 N = 20 而非單次計時。
  • 是否討論擺長範圍？橫軸跨度愈大斜率愈準，但受 45 cm 直尺與短擺長物理擺修正兩頭夾擊。
  • 是否檢視殘差？短擺長端若系統性偏離直線，應指出是擺錘非質點所致。
  • 是否與公認值比較？以「相差幾個標準差」而非單純百分誤差來評估，才是統計上有意義的說法。
