第 1 題　落球運動方程式與終端速度

密度 ρ 之圓球在密度 ρ′ 之液體中落下，受三力：重力、浮力、黏滯阻力。題目給定黏滯阻力形式為

F = 6π η rm vt　……(1)

（當 m = 1 時即為標準的 Stokes 定律 F = 6πηrv。題目刻意把指數寫成未知的 m，要你用實驗去驗證它。）

運動方程式

4⁄3πr³ρ · dv/dt = 4⁄3πr³ρg − 4⁄3πr³ρ′g − 6πηrmv

終端速度（dv/dt = 0，合力為零）

4⁄3πr³ρg = 4⁄3πr³ρ′g + 6πηrmvt 　⟹　4⁄3πr³g(ρ−ρ′) = 6πηrmvt
vt = 2g / (9η) · r3−m(ρ−ρ′) 　⟹　c = 2g / (9η)
這就是整份試題的骨架。後面每一題都只是在這條式子上改變「哪個量當自變數」：
第 3 題固定液體與材質、變動 r → 由 ln vt–ln r 的斜率 (3−m) 求 m；
第 4 題固定 r、變動材質密度 ρ → 由 vt–ρ 的 x 截距求 ρ′；
第 5 題固定球、變動管半徑 R → 檢驗管壁修正因子。

互動：三力平衡與終端速度

此處為無限廣闊液體中的理論值（不含管壁修正），僅示範式 (1) 的行為。 m ≠ 1 時 r3−m 的單位並不一致，這是題目為了「用指數檢驗定律」而做的簡化。

第 5 題　管壁效應的檢驗與修正

固定使用直徑 9.7 mm 的鋁球，改變壓克力管的管徑（內徑 26、36、46、56 mm）。

(a) Ladenburg (1907)　式 (2)

F = 6πηrmvt(1 + 2.1 r/R) 　⟹　vt = C r3−m(ρ−ρ′)(1 + 2.1 r/R)−1
ln vt = −1·ln(1 + 2.1 r/R) + 常數

作 ln vt–ln(1 + 2.1 r/R) 圖，若式 (2) 成立，斜率應為 −1。

(b) Francis (1933)　式 (3)

F = 6πηrmvt·[(1 − 0.475 r/R)/(1 − r/R)]n
ln vt = −n·ln[(1 − 0.475 r/R)/(1 − r/R)] + 常數

作對應圖形，斜率的負值即為 n。

實驗誤差來源

一、系統誤差（會使結果偏向同一邊，無法靠多次平均消除）

  • 管壁效應——本實驗最大的系統誤差。球越大，液體被迫在球與管壁之間回流的阻力越大， 量到的終端速度系統性偏低。這正是第 3 題 m 值偏離 1 的元兇，也是整份試題的主題。
  • 反應時間——按碼錶的延遲約 0.15～0.25 s。它對每一條刻度線幾乎相同， 因此只會平移 x–t 直線的截距，不會改變斜率。這就是題目要求作線性迴歸、 而不是用單點「距離 ÷ 時間」相除的根本理由。
  • 視差——眼睛未與刻度線齊平，判讀球心通過的時機會固定偏早或偏晚。
  • 甘油吸濕——甘油暴露在空氣中會吸收水分，黏度隨時間下降。 先量的數據與後量的數據對應到不同的 η，會使跨組比較產生偏差。
  • 管子未鉛直——球會偏向一側下落，受到額外的近壁阻力。
  • 球徑公差——標稱 4.00 mm 的球實際可能是 3.98 mm。因 v ∝ r²，0.5% 的直徑誤差造成 1% 的速度誤差。

二、隨機誤差（可靠多次量測平均縮小）

  • 每次按碼錶的反應時間有快有慢（標準差約 0.05 s）。
  • 前一顆球造成的液體擾動尚未完全靜止。
  • 球表面附著的微小氣泡（使有效密度下降、有效半徑變大）。
  • 液體局部溫度不均造成黏度微小起伏。

三、改善方法

  • 用迴歸取代相除：多點 x–t 線性迴歸可自動消去反應時間造成的截距偏移。
  • 第一條刻度線離液面夠遠：確保球已達終端速度再開始計時（本實驗時間常數 τ 極小，約 1 mm 內即達終端速度，但液面附近仍有入液擾動）。
  • 沿管壁緩慢注入液體，並讓球先沾濕或用鑷子貼著液面釋放，避免帶入氣泡。
  • 眼睛與刻度線齊平，並全程追視球體，減少視差。
  • 同一尺寸重複多次取平均，並檢查各次速度是否一致。
  • 設計投球順序使不必中途撈球——撈球會大幅擾動液體。（題目備註即暗示此點）
  • 套用管壁修正：將量到的 vt 乘上 Francis 因子還原為無限液體中的值，即可消去最大的系統誤差。
