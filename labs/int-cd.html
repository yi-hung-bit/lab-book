光碟軌道溝槽間距 a 的量測

光碟片表面密排的螺旋溝槽就是一面現成的反射式光柵。用波長 658.5 nm 的雷射照射它，在方格紙上量出各級繞射光點的位置，就能反推出肉眼看不見的軌道間距。

光碟片為什麼是光柵

CD 的資料以一條由內向外的螺旋狀溝槽記錄，相鄰圈之間的距離就是題目要求的 a。在雷射光斑照到的那一小塊區域（直徑約 1～2 mm）內，這些螺旋可以視為一組等間距的平行直線，因此整片光碟對雷射而言，等效於一面週期為 a 的光柵。

由於鋁膜會把光反射回來，未經處理的光碟是反射式光柵；若把鋁膜剝除，留下的透明聚碳酸酯基板仍保有溝槽的起伏，就變成穿透式光柵。兩者的繞射公式完全相同。

光柵方程式

a ( sin βm − sin α ) = m λ α：入射角；βm：第 m 級繞射角（皆自光碟法線量起）；λ = 658.5 nm；m = 0, ±1, ±2, …

若把雷射調到垂直入射（α = 0），公式簡化為：

sin βm = m λ / a　　⟹　　a = m λ / sin βm

以 CD 規格值 a ≈ 1.6 μm 估算：第一級 β₁ ≈ 24°，第二級 β₂ ≈ 55°，而第三級需要 3λ/a = 1.23 > 1，不存在。所以這片光碟在這支雷射下最多只能看到 ±1、±2 兩組繞射光點。

怎麼把角度換成長度

角度不能直接量，但方格紙上的長度可以。把方格紙平行於光碟放在距離 L 處，第 m 級光點落在離中央 0 級光點 xm 的位置：

tan βm = xm / L

單測一組 (x, L) 就能算出一個 a，但那等於把全部誤差壓在一次讀數上。更好的做法是改變 L 量多組 x：由於 β₁ 只由光碟決定、與 L 無關，理論上

x₁ = ( tan β₁ ) · L x₁ 對 L 作圖應為通過原點的直線，斜率 k = tan β₁

斜率取自最小平方法，等於讓每一筆數據都貢獻資訊；而截距是否接近 0，正好可以檢查系統誤差（例如 L 的起算點量錯）。求得 k 之後：

sin β₁ = k / √(1 + k²)　　⟹　　a = λ / sin β₁

一個實作上的關鍵

不要去量「0 級到 +1 級」的單邊距離——0 級光點的中心位置最難認定（反射式時它還會從紙上的小孔穿回去）。改量左右兩個同級光點之間的總距離 D，再取 x = D/2。這樣不需要知道中心在哪裡，而且讀數誤差被除以 2，同時左右對稱與否還能當作準直的檢查。

選擇實驗路線

反射式

雷射穿過方格紙中央的小孔打在光碟上，繞射光再反射回方格紙成像。不必破壞光碟，但方格紙要挖孔，且必須確認光束垂直入射。

穿透式

用小刀沿光碟邊緣劃開保護漆，再以膠帶把鋁反射層整片撕下，得到透明光柵。光路是一直線，架設與對準都容易得多，代價是犧牲一片光碟。

實驗報告該寫什麼

評分依據是報告本身，以下是這一題最容易被扣分、也最容易拿分的幾個地方。

必須交代的設計理由

  • 為什麼選反射式或穿透式，以及該路線的架設細節。
  • 為什麼量 ±m 級的總距離 D 而不是單邊距離。
  • 為什麼改變 L 取多組數據作圖，而不是單點代入公式。
  • 如何確認雷射垂直入射（這是本題最大的系統誤差來源）。

作圖與計算

  • 橫軸 L、縱軸 x，標明單位與刻度，畫出最適直線並標示斜率的求法。
  • 由斜率 k 得 sin β = k/√(1+k²)，再代回 a = mλ/sin β。不要直接寫「sin β ≈ tan β」——β₁ 約 24°，兩者相差 1/cos β₁ ≈ 1.10，會讓 a 低估約 9%。
  • 第 1 級與第 2 級分別分析，兩者結果若一致，是內部自洽性的有力證據。

誤差來源

系統誤差

  • 入射不垂直。α ≠ 0 時 +m 與 −m 級不再對稱，取平均仍殘留 tan 函數非線性造成的偏差。α = 3° 約造成 a 偏低 0.9%，在本實驗的統計誤差下已是可偵測的顯著偏差。判斷方式：0 級光點是否回到小孔上、左右一級光點到 0 級的距離是否相等。
  • 方格紙不平行光碟。會讓兩側的有效 L 不同，同樣破壞對稱。
  • L 的起算點。應從光碟表面量起，不是從支架或紙盒邊緣。此誤差會反映在迴歸截距上。

隨機誤差

  • 光點有大小。雷射光斑本身約 1～3 mm，高階光點還會因溝槽不完全等距而稍微拉長，中心判定約有 ±0.5 mm 的不確定度。
  • 方格紙讀數。1 mm 方格可估讀到 0.5 mm。
  • L 的量測。直尺最小刻度 1 mm，加上垂直度判斷，實務上約 ±1 mm。

以迴歸斜率的標準誤差 σk 傳遞到 a：σa = (mλ / sin²β) · σk / (1+k²)3/2。

延伸問題

  1. 為什麼看不到第三級？因為 3λ/a > 1，sin β 無解。反過來說，若改用 DVD（a ≈ 0.74 μm），連第二級都會消失（2λ/a = 1.78 > 1）——這正好成為分辨 CD 與 DVD 的判據。
  2. 光碟能存多少資料？CD 記錄區從半徑 23 mm 到 58 mm，軌道總長 ≈ π(58² − 23²) / a（單位 mm）。代入 a = 1.6 μm 約得 5.6 km 的螺旋長度，配合每個記錄坑的長度即可粗估容量。
  3. 寶特瓶還能怎麼用？裝滿水的圓柱瓶身是一個柱面透鏡，可把雷射點展開成一條垂直亮線。讓亮線橫跨光碟上多條軌道，繞射光在紙上也成為亮線，中心位置反而更容易判定。這是本題器材表的另一種解讀。
  4. 如果雷射波長未知呢？反過來用規格值 a = 1.6 μm 的 CD 當標準光柵，就能測未知光源的波長。
