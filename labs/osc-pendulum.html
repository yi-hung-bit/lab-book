大角度單擺虛擬實驗室

98 學年度高中數理及資訊學科能力競賽第 10 區複賽｜物理科實驗試題第一題

題目

單擺在小角度擺動時，週期 T 與擺長 ℓ 遵守 T = 2π√(ℓ/g)。擺角 θ 不夠小時，此公式需要修正。請利用下列器材設計實驗，修正此公式。

題目提示：下列四個公式中，有一個是較適當的可能。

(1)　T = 2π √( ℓ cosθ / g )
(2)　T = 2π √( ℓ / (g cosθ) )
(3)　T = 2π √( ℓ sinθ / g )
(4)　T = 2π √( ℓ / (g sinθ) )

提示只是「可能」。你的數據才是判斷的依據——請讓實驗結果決定哪個公式能描述單擺，也要準備好面對「四個都不夠好」的可能。

器材

螺絲帽（約 20～25 g）一個、棉線一卷、免洗竹筷一雙（夾住棉線，固定懸點）、透明膠帶、量角器、卷尺（最小刻度 1 mm）、支架（橫桿可在 120 cm 範圍內調整）、碼表（最小刻度 0.01 s）、天平（最小刻度 0.01 g）。

設計思路

週期受擺長和擺角兩個因素影響，實驗需要把兩者分開處理。

第一步，在小擺角（例如 5° 以下）測不同擺長的週期，以 T² 對 ℓ 作最小平方法回歸，得到小角度週期 T₀(ℓ)。回歸的截距能告訴你擺長量測是否有系統誤差，例如是否量到螺絲帽的質心。

第二步，固定擺長，改變釋放角（例如 10° 到 80°），量測週期 T，計算比值 T/T₀。四個提示公式分別預測：

(1)　T/T₀ = √cosθ
(2)　T/T₀ = 1/√cosθ
(3)　T/T₀ = √sinθ
(4)　T/T₀ = 1/√sinθ

把 T/T₀ 對 θ 作圖，與四條曲線比較，並以量測不確定度評估每個公式的偏差有多少個標準差。

操作上要注意的地方

一次量多個週期再平均，可降低按碼表反應時間造成的相對誤差。空氣阻力會讓振幅逐漸變小，大角度時尤其明顯，所以要記錄開始與結束時的振幅。按下「釋放擺錘」時碼表會同步開始，數滿 N 個週期、擺錘回到釋放側最高點時按停止。最高點附近擺錘移動很慢，停止的瞬間較難判斷，請仔細觀察。

揭曉隱藏參數

揭曉後，分析頁會加入精確理論曲線。建議先完成自己的結論再按。

理論：大角度單擺的精確週期

單擺的運動方程式是 d²θ/dt² = −(g/ℓ) sinθ。小角度時 sinθ ≈ θ，才得到簡諧運動與 T₀ = 2π√(ℓ/g)。振幅為 θ₀ 時，由能量守恆積分可得精確週期：

T = T₀ · (2/π) · K(k)，　k = sin(θ₀/2)

K 是第一類完全橢圓積分。展開成級數：

T = T₀ [ 1 + (1/4) sin²(θ₀/2) + (9/64) sin⁴(θ₀/2) + … ]
　≈ T₀ [ 1 + θ₀²/16 + 11θ₀⁴/3072 + … ]

本模擬器即以此非線性方程式（加上空氣阻力）做數值積分；分析頁的精確曲線由算術幾何平均計算：T/T₀ = 1 / AGM(1, cos(θ₀/2))。

四個提示公式的問題

四個提示公式都不是正確的修正式。

公式 (3)、(4) 在 θ → 0 時分別趨近 0 與無限大，無法回到小角度公式，可以直接排除。公式 (1) 預測週期隨擺角變短，與實驗趨勢相反。

公式 (2) 的趨勢正確，但展開後為 T₀(1 + θ₀²/4 + …)，二次項係數是正確值 1/16 的 4 倍；以 sin²(θ₀/2) 表示時，斜率約為 1，而正確值約為 0.25。在 30° 時它已高估約 5.6%，擺長 1 m、量 10 個週期時相當於 1 秒以上，用碼表就能分辨。

公式 (2) 常見的來由是「擺錘在 θ 處受的等效重力為 g cosθ」，但這個論證有兩個錯誤：切線方向的回復力是 mg sinθ 而非 mg cosθ，而且擺角在整個週期中不斷變化，不能用最大擺角處的值代表整個運動。

討論題

1. 空氣阻力使振幅隨時間變小，你量到的週期對應的是哪一個擺角？用 θ₀ 與用 θ̄ 作圖，結果有什麼差別？

2. 小角度回歸的截距代表什麼？如果只量棉線長而忽略質心位置，g 的結果會受影響嗎？

3. 本實驗從釋放瞬間開始計時、在擺錘回到最高點時停止。若改成在擺錘通過最低點時開始與停止，計時誤差會變大還是變小？為什麼？

4. 螺絲帽有大小，嚴格來說是物理擺。估算這個修正對週期的影響有多大，與擺角修正相比是否可忽略？

5. 支架高度限制擺長不超過約 110 cm。若要更準確地驗證 θ₀²/16 項，應如何選擇擺長、週期數與擺角？
