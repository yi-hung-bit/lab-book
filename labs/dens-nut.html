螺絲帽密度虛擬實驗室

九十七學年度高級中學自然學科競賽 屏東區複賽 物理科實驗試題第二題 ── 無天平、無量筒：以「金屬線當砝碼、幾何量體積」求螺絲帽密度

① 實驗設計之理論基礎

器材清單中沒有天平、沒有量筒、也沒有水，所以密度 ρ = m／V 的兩個量都得「自己造標準」：

  • 質量標準：金屬線單位長度質量 μ = 0.05 g/cm 已知，剪一段量長度 L，就得到已知質量 mw = μL 的「砝碼」（整條約 70 cm ≈ 3.5 g）。
  • 體積：沒有水可排，只能用直尺／卷尺量幾何尺寸。50 個螺帽可以疊高、並排，用迴歸把 1 mm 刻度的誤差分攤掉。

法一（主）：竹筷槓桿

竹筷以棉線吊在支架橫桿上。先找筷子自身的平衡點當支點，使筷子自重對支點的力矩為零。左側距支點 a 處掛 n 顆螺帽，右側在 x 處掛已知質量 mw 的金屬線，調 x 使筷子水平：

n·m·a = mw·x　⇒　令 X = n·a，Y = mw·x，則 Y = m·X + b

斜率就是單顆螺帽質量 m。若支點與筷子重心相差 δ，筷子自重 Mc 會多出力矩 Mcδ，它只進入截距 b、不影響斜率──這正是用迴歸而不用單點 m = Y／X 的理由。

法二（對照）：定滑輪 Atwood 機

兩側各掛 N 顆螺帽，右側再加金屬線 Δm，由靜止釋放，量下落高度 h 與時間 t，a = 2h／t²。考慮滑輪轉動慣量 I（半徑 r）與摩擦（等效質量 f）：

a = (Δm − f)g ／ (2Nm + Δm + I/r²)
忽略 f：1/a = [2m／(Δm·g)]·N + (Δm + I/r²)／(Δm·g)

作 1/a–N 圖，斜率 s ⇒ m = s·Δm·g／2；截距還可估出滑輪等效質量 I/r²。台灣 g ≈ 979 cm/s²。

體積：六角柱扣掉螺紋孔

V = [ (√3/2)·F²·(1 − c) − (π/4)·deff² ]·t
  • F：對邊寬（兩平行邊距離），t：厚度。六角形面積 = (√3/2)F²。
  • 疊 n 顆量總高 H、並排 n 顆（平邊相貼）量總寬 W，作 H–n、W–n 迴歸，斜率即 t、F，零點讀數誤差落在截距。
  • 螺紋修正：孔壁是內螺紋，直接量到的是小徑 D₁（牙頂）。牙在 D₁～D（大徑）之間大約一半是實心，故 deff² ≈ (D₁² + D²)/2；公制粗牙螺紋 D₁ ≈ 0.83 D。
  • 倒角修正 c：市售六角螺帽兩面都有 30° 倒角，邊角被削掉，體積比理想六角柱少約 2～4%。並排量「對角寬」e 並與理想值 2F/√3 比較，可看出邊角被削的程度。

誤差傳遞

(σρ/ρ)² = (σm/m)² + (σV/V)²，　σV² = (∂V/∂F·σF)² + (∂V/∂t·σt)² + (∂V/∂d·σd)²

∂V/∂F = √3·F·t·(1−c) 是最大的一項，所以 F 要量得最準（並排越多顆越好）；孔徑 d 雖然只用直尺量很粗，但孔面積只佔六角形約 25～30%，影響被壓小。最後以 (測量值 − 真值)／σ 檢驗結果是否在誤差範圍內。

本實驗室的流程

② 剪金屬線、量長度、找筷子平衡點 → ③ 槓桿 Y–X 迴歸求 m → ④ Atwood 1/a–N 迴歸求 m（對照）→ ⑤ 疊高／並排／孔徑求 V → ⑥ ρ、誤差傳遞、材質判斷、真值揭曉。

每次開啟都會隨機抽出一組「隱藏真值」：螺帽規格（M6／M8／M10 其中之一）、材質、每顆螺帽的尺寸與質量散佈、金屬線實際 μ、筷子重心、滑輪轉動慣量與摩擦。真值只在 ⑥ 揭曉。

真值揭曉

報告撰寫檢核（對應評分比例）

  • 理論基礎 20%：槓桿力矩平衡、Atwood 加速度式、六角柱體積公式、為何用迴歸。
  • 實驗步驟 20%：剪線量長、找平衡點、改變 n 與 a、疊高並排、孔徑量法。
  • 數據記錄 10%：所有讀數含單位與估計位，重複次數。
  • 計算分析與結果 25%：迴歸斜率與標準差、m、V、ρ ± σ。
  • 討論 25%：支點偏移只影響截距、滑輪摩擦使 Atwood m 偏大、螺紋與倒角修正、金屬線 μ 的不確定度、材質判斷的極限。
