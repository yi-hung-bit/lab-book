真實度設定（預設全開）

題目分析：沒有碼錶，時間從哪裡來？

器材表中沒有碼錶，也沒有任何計時器。要量「時間」，就得自己造一個鐘，也就是一個週期穩定、且週期可由已知量算出的振盪系統。可用的有兩種：

  • 單擺：棉線加 50 g 掛碼。週期只和擺長及 g 有關，擺長可以用捲尺量。
  • 彈簧振子：彈簧加 50 g 掛碼。週期和 k、掛碼質量、彈簧自身質量都有關，這些量在現場量不準（理由見第 5 節）。

唯一可用的「標準」是當地重力加速度 g（本模擬取 g = 9.79 m/s²，臺灣中部實際約 9.789 m/s²），以及捲尺上的長度刻度。

1　單擺當作時鐘

T = 2π √( ℓ / g )，　ℓ = L + d

L：懸點到棉線結點的距離，可以用捲尺量。
d：結點到掛碼質心的距離。掛碼的鉤子與本體形狀不規則，質心位置只能估計。

在沙漏漏沙期間數擺動次數 N，就能換算出時間：

ts = N · T

舉例：ℓ = 1.00 m 時 T ≈ 2.01 s。若沙漏約 2 分鐘漏完，N ≈ 60 次；只要 N 能讀到 ±0.05 次，相對誤差就小於 0.1%。所以精度的關鍵是最後那一次不完整擺動的分數要估準。

精確來說，掛碼有大小，屬於複擺。等效擺長為 ℓeq = ℓ + κ²/ℓ，其中 κ 是掛碼對質心的迴轉半徑（約 1 cm）。擺長 1 m 時修正量約 0.01 cm，可忽略。

漏沙的一兩分鐘內，空氣阻力與懸點摩擦會讓擺幅逐漸衰減，實際週期也跟著縮短。擺角取 10° 以內時，這項系統誤差小於 0.2%，而且擺幅衰減的影響也跟著變小。

擺角太小也不行：擺幅過小時，最後一次擺動的分數難以判讀。擺角要在「修正量小」與「讀得清楚」之間取捨。

3　數擺動次數與「分數次」的估計

約定：擺錘由右端（釋放側）靜止放開。每次擺回右端，就算完成 1 次擺動。沙漏漏完的瞬間：

N = N整 + f　（0 ≤ f < 1）

擺動可以看成參考圓上等速轉動的投影。以擺錘正下方的直尺讀出左、右兩端讀數 x左、x右 以及該瞬間的位置 x，則：

中心 c = (x左+x右)/2，　振幅 A = (x右−x左)/2
φ = arccos[ (x − c) / A ]
向左運動：f = φ / 2π　　向右運動：f = 1 − φ / 2π

直尺的零點不必對準平衡位置，用兩端讀數的中點當中心即可，零點誤差會自動抵消。

拖曳 f：f = 0.300

4　迴歸設計：讓未知的 d 從截距跑出來

把 T = 2π√((L+d)/g) 代入 N = ts/T，兩邊平方後取倒數：

1/N² = [ 4π² / (g ts²) ] · L　+　[ 4π² / (g ts²) ] · d

改變擺長 L，每個擺長各讓沙漏漏完一次並記下 N，再作 y = 1/N² 對 x = L 的最小平方直線，斜率為 m、截距為 b：

ts = 2π / √( g·m )　，　d = b / m
為何不用單點法？單點法的 ts = N·2π√((L+d)/g) 需要知道 d。若 d 用「鉤長＋本體高度的一半」來估，只要估錯 0.3 cm，在擺長 50 cm 時 ts 就偏差 0.3%。迴歸法把 d 當未知數求出，不必估計；還能順便檢驗各數據點是否落在同一直線上，找出數錯次數的離群點。
沙漏的兩端可能不一樣。商用沙漏的兩個玻璃泡與沙量很少完全對稱，每翻一次就換一端朝上。記錄時務必註明是哪一端朝上，分析時兩端分開處理（或先檢驗兩端是否有差異）。

5　為何彈簧只當對照？

彈簧振子週期為

T = 2π √( (m + ms/3) / k )

現場沒有天平，k 只能用靜伸長求：掛上 50 g 時伸長 Δx，得 k = mg/Δx，代入後

T = 2π √( Δx / g ) · √( 1 + ms/(3m) )

彈簧質量 ms 未知，第二個根號無法修正，所以此法必定低估週期。此外 Δx 只有幾公分，1 mm 的讀數誤差就造成約 1–2% 的週期誤差。第 ⑤ 頁會用它當對照，示範這個系統誤差的大小。

6　操作要點

  1. 懸點要固定：用兩支免洗筷夾住棉線並用膠帶纏緊，再把筷子夾在直角夾上，使懸點固定在筷子下緣。
  2. 同步開始：翻轉沙漏與放開擺錘要在同一瞬間（本模擬用同一個按鈕觸發兩者，但仍保留人手的不同步誤差）。
  3. 「漏完」要有一致的定義：主沙流停止後，還會斷續落下幾粒細沙。本實驗以「最後一粒沙落下」為準，每次都要用同一個標準判定。
  4. 擺錘在同一鉛直面擺動：放手時不要推，避免擺錘走橢圓軌跡。
  5. 擺長盡量拉開差距：可用約 30–120 cm 的範圍，取 5 個以上擺長，迴歸結果才可靠。

C　討論題

  1. 擺角的取捨：θ₀ = 20° 時振幅修正約 0.76%，θ₀ = 3° 時只有 0.02%。但擺幅越小，停格時越難判斷擺錘位置，分數 f 也估不準。請用你的數據說明你選擇的擺角。
  2. 為什麼要讓 d 從截距跑出來？比較第 ④ 頁單點法 (i) 與 (ii) 的差異：a + h/2 的估計偏差了多少？對 ts 造成多少百分比誤差？擺長較短時影響是變大還是變小？
  3. 沙漏兩端：A、B 兩端的 ts 差異有沒有超過 2 倍合成標準差？若有，題目問的「沙漏漏完所需時間」應該怎麼回答？
  4. 懸點：繞桿打結時，棉線在圓桿上滾動，有效懸點比桿下緣略低（擺長偏長），擺幅也衰減得比較快。它對 ts、d 的影響分別會出現在迴歸的斜率還是截距？
  5. 彈簧法：彈簧法算出的時間比單擺法短多少？這個差異能不能完全用 ms/3 解釋？捲尺讀 Δx 的 ±0.05 cm 會讓 T預 產生多少百分比的不確定度？
  6. 「漏完」的定義：主沙流停止到最後一粒沙落下之間大約有 1 秒。若改用「主沙流中斷」來判定，結果會系統性地偏短多少？
