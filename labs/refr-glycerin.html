第 1 小題：臨界角與折射率的關係（10 分）

由 Snell's Law：n₁ sinθ₁ = n₂ sinθ₂

當 n₁ > n₂，折射光會偏離法線（θ₂ > θ₁）。逐漸加大 θ₁，θ₂ 會先達到 90°，此時的入射角即為臨界角 θc：

n₁ sinθc = n₂ sin90° = n₂  ⟹  θc = sin⁻¹(n₂ / n₁)

本實驗中 n₁ = n甘油、n₂ = n空氣 = 1，故 θc = sin⁻¹(1/n甘油)。當 θ₁ ≧ θc 時折射光消失，入射光能量全部回到原介質，即全反射。

第 2 小題：平行平板的 B 點能全反射嗎？（10 分）

不能，B 點永遠不會發生全反射。

  1. A 點（n₂ → n₁，n₁ > n₂）：n₂ sinθA = n₁ sinθ′A ⟹ sinθ′A = (n₂/n₁) sinθA ≦ n₂/n₁ = sinθc。
  2. 平板上下表面平行 ⟹ B 點的入射角 θB = θ′A。
  3. 因此恆有 θB ≦ θc，等號只在 θA = 90°（掠射）時成立，而掠射時光強度趨近於零。

結論：光由外部射入平行平板後必能射出，且出射光與入射光平行（僅產生側向位移）。這正是「只要光的來源在平板外，就不可能靠調整入射角讓它在對面全反射」。

延伸：為什麼「直立桶壁」量不到臨界角？

液面（水平）與桶壁（鉛直）互相垂直。光由液面折射入甘油後與鉛直線夾 θ₂，打到桶壁時的入射角為 90° − θ₂。由於任何從空氣射入的光必有 θ₂ ≦ θc：

θ壁 = 90° − θ₂ ≧ 90° − θc

甘油 n ≈ 1.47 時 θc ≈ 42.8°，而 90° − θc ≈ 47.2° > θc。也就是說，只要 n > √2 ≈ 1.414，射到桶壁的光一定全反射，永遠看不到「剛好開始漏光」的門檻。第 4 小題必須改用其他設計（掠射極限法／傾斜桶身法），這點會在分頁 ⑤ 處理。

第 3、4 小題的實驗設計構想

求折射率 n（第 3 小題，40 分）

量出多組 (θ₁, θ₂)，把 sinθ₂ 當 x 軸、sinθ₁ 當 y 軸作圖，由 Snell's Law：

sinθ₁ = n · sinθ₂  （過原點的直線，斜率即為 n）

「非常有技巧的處理數據」指的就是：量到的是長度，先換成 tanθ，再換成 sinθ，才會得到線性關係。另一條對照路線是固定入射角、逐次加深液深 h，量底部光點位移 x：

x = h · tanθ₂ + x₀  （x–h 直線，斜率 = tanθ₂）

求臨界角（第 4 小題，30 分）

  • 掠射極限法：雷射貼近液面以 θ₁ → 90° 入射，此時 θ₂ → θc（光路可逆）。量底部光點的最大偏移 xmax = h·tanθc，並以 x–sinθ₁ 外插至 sinθ₁ = 1。
  • 傾斜桶身法：雷射鉛直射入（不折射），把桶身夾斜 β 角，桶底法線與光線夾角即為 β。當 β ≧ θc 時桶底下方的光點消失（全反射）。θc = β門檻。

量測原理：不用量角器，怎麼量 θ₁ 與 θ₂？

入射角 θ₁（全部在空氣中，可直接用鉛錘線與直尺）：

tanθ₁ = (xO − xS) / (H + Δ)

xS：筆尖鉛錘線落在桶緣尺上的讀數；H：桶緣到筆尖的垂直高度；Δ：桶緣到液面的垂直距離；xO：光束射入液面的入射點（用第二條棉線鉛錘對位，讀桶緣尺）。

折射角 θ₂（在甘油中，用液深與底部光點位移）：

tanθ₂ = (xB − xO) / h

xB：桶底標尺上紅色光點的讀數；h：液深。所有 x 讀數都以同一面桶壁為原點（桶緣尺與桶底標尺對齊）。

由 tan 換回 sin：sinθ = tanθ / √(1 + tan²θ)。取得多組 (sinθ₂, sinθ₁) 後到分頁 ④ 做線性迴歸，斜率即為甘油折射率。建議取 6–8 組，讓 sinθ₁ 平均分布在 0.2 ~ 0.85 之間。
