理論推導

光以入射角 θ 射到平板上表面 P 點：一部分直接反射成為光束 A；其餘折射進入板內（折射角 Φ），在下表面反射後從上表面 Q 點射出，成為光束 B。若上下表面平行，A、B 兩光束平行。

① 司乃耳定律：

sinθ=nsinΦ

② 兩出射點的水平距離：

PQ‾=2ttanΦ

③ 兩平行光（與鉛直方向夾 θ）水平錯開 PQ，打在鉛直屏幕上的高度差 x 滿足 x·tanθ = PQ：

xtanθ=2ttanΦ

④ 整理：

x=2tsinΦcosθcosΦsinθ=2tcosθncosΦ=2tcosθn2−sin2θ

⑤ 平方取倒數並用 sin²θ = 1 − cos²θ，得線性關係：

1x2=n2−14t2·1cos2θ+14t2
講義勘誤：參考解答的推導第三行寫成 x = 2t·cosθ / cosΦ，漏了分母的 n；正確為 x = 2t·cosθ / (n cosΦ)。由於 n cosΦ = √(n² − sin²θ)，講義的最終式與上面 ④、⑤ 一致，結論不受影響。
x 的定義：x 是兩光點在鉛直屏幕上的高度差，不是兩平行光束之間的垂直距離 d⊥ = 2t tanΦ cosθ。兩者相差 cosθ·tanθ = sinθ 倍，屏幕若斜放，上式就不成立。

為什麼要「找平行」

實際的壓克力板上下表面不會完全平行，而且楔角隨位置而變。下表面傾 α，板內反射光就偏轉 2α，出射後偏轉約 2nα·cosΦ/cosθ。θ 越大放大越多：在 θ = 60°、屏幕相距 25 cm 時，α 僅 0.03°，x 就會差約 0.08 cm。

因此實驗關鍵是：換不同入射點，分別量近屏與遠屏的 x，找出兩者相等的位置（此處 A、B 平行），才採用該 x。第 ③ 分頁就是模擬這個過程。

由迴歸求 n 的兩種算法

設斜率 m = (n²−1)/(4t²)、截距 b = 1/(4t²)：

（甲）斜率＋實測厚度：n = √(1 + 4t²·m)
（乙）斜率 ÷ 截距（不需 t）：n = √(1 + m/b)

用參考解答的數據核對（t = 0.779 cm，m = 0.4481，b = 0.3727）：
（乙）n = √(1 + 0.4481/0.3727) ≈ 1.484，也就是講義寫的 1.48
（甲）n = √(1 + 4×0.779²×0.4481) ≈ 1.445
理論截距 1/(4t²) 應為 0.412，回歸卻得 0.373（差約 10%）。兩法都落在壓克力的 1.41–1.49 之間，但這個差異正好指出截距對誤差很敏感。第 ④ 分頁會把兩種算法並列比較。
