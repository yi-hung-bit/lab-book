題目重點

電阻器網路可當作音量控制電路，稱為「電阻衰減器」（圖一）。適當選擇 R1 與 R2，可使輸入電源所見等效電阻 Rab = RL = 20 Ω。要求：(1) 設計 R1、R2 並量 Vi、i，完成表一並作圖三（R1 對 R1+R2）；(2) 由圖三找出 R1、R2、RL 的關係並推導；(3) 討論實驗與理論的誤差。

圖一　電阻衰減器電路

四個 R1 對稱分布於上下兩條線，R2 跨接中間，RL 為負載（喇叭）。

推導 RL2 = 4R1(R1+R2)

Rab = 2R1 + R2 ∥ (2R1 + RL)左側兩個 R₁ 串聯，再串上並聯部分
令 Rab = RL：　RL − 2R1 = R2(2R1+RL) / (R2+2R1+RL)
(RL − 2R1)(R2 + 2R1 + RL) = R2(2R1 + RL)
RLR2 + RL2 − 2R1R2 − 4R12 = 2R1R2 + RLR2±2R₁RL 互相消去
RL2 = 4R1(R1 + R2)

由此可得

  • R1·(R1+R2) = RL2/4 = 100 Ω2（RL=20 Ω）→ R1 與 R1+R2 成反比，圖三為雙曲線。
  • R2 = RL2/(4R1) − R1 ≥ 0，故必須 R1 ≤ RL/2 = 10 Ω。
  • 匹配時衰減比 VL/Vi = (RL − 2R1)/(RL + 2R1)；因為 Rab 仍是 RL，衰減器可一節一節串接。

② 電阻鑑定：A–F 六種電阻阻值未標示

器材表只寫「編號 A～F 各 8 個」，沒有給阻值，器材中也沒有現成的 20 Ω 電阻。所以第一步要用電池、安培計、伏特計自己量出每種電阻的阻值：改變電池個數取得多組 (I, V)，再以 V–I 迴歸斜率求 R。

④ 量測 Vi、i，完成表一

表一需要至少 4 組不同的 R1，每組都要讓 Rab = Vi/i 盡量等於 RL。有兩種取得數據的方式：

  • 直接匹配：用現有電阻組出最接近理論值的 R2，量一次記入表一。受限於電阻只能離散組合，Rab 通常只能「接近」RL。
  • 固定 R1、掃描 R2 內插：保持 R1、RL 不變，換幾種 R2（有的偏小、有的偏大）各量一次 Rab，再內插出 Rab = RL 時的 R2。這樣即使沒有剛好的電阻，也能得到精確的匹配點。

⑤ 作圖分析：由圖三找 R1、R2、RL 的關係

原題的圖三是 R1 對 R1+R2，點會落在雙曲線上，肉眼只能看出「反比」。把橫軸改成 1/(R1+R2) 就會變成直線：R1 = (RL2/4) · 1/(R1+R2)，斜率 k = RL2/4，可用迴歸求出 RL = 2√k 並估計不確定度。

結果

題目 (2) 的回答要點

  1. 圖三的點落在一條雙曲線上：R1 愈大，R1+R2 愈小，兩者成反比。
  2. 理論推導（見 ①）：Rab = 2R1 + R2 ∥ (2R1+RL) = RL ⇒ RL2 = 4R1(R1+R2)，乘積 R1(R1+R2) 是常數 RL2/4。
  3. 實驗驗證：線性化後斜率求得的 RL 與 20 Ω 比較，截距應接近 0。
  4. 限制條件：R2 ≥ 0 ⇒ R1 ≤ RL/2，曲線止於 (RL/2, RL/2)。
