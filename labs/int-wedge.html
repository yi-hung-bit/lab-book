條紋從哪裡來

兩片玻片一端直接接觸、另一端夾入待測金屬線，中間夾出一層厚度沿長度線性變化的空氣楔。從上方入射的光，一部分在上玻片的下表面反射（玻璃→空氣），一部分穿過空氣層後在下玻片的上表面反射（空氣→玻璃）。

兩道光的幾何光程差是 2d（近法線入射、空氣 n ≈ 1）。光線②在光密介質表面反射，額外多了 π 的相位差，因此：

2d = nλ暗紋，n = 0, 1, 2, …
2d = (n + ½)λ亮紋

d = 0 的接觸線本身是暗的，這是檢查玻片有沒有真正貼合的最快判據：如果最邊緣那條不是暗的，中間就有灰塵。

怎麼換成線徑

楔形是線性的，距接觸線 y 處的膜厚為 d = D · y / L。代入暗紋條件：

yn = (λL / 2D) · n

所以 yn 對 n 作圖是一條過原點的直線，斜率 s = λL / 2D，於是

D = λL / 2s

相鄰兩條暗紋的間距就是 Δy = λL / 2D。這個式子是整個實驗的成敗關鍵：D 越粗，條紋越密。L = 75 mm、λ = 611 nm 時，D = 0.036 mm 給出 Δy = 0.64 mm，放大鏡下數得動；D = 0.25 mm（漆包線沒刮漆）只剩 0.092 mm，已經在肉眼與普通放大鏡的解析極限之外。

為什麼遠離接觸線就糊掉

光源不是單色的。頻寬 Δλ 的光，各波長的條紋位置不同，到了第 N 級時互相錯開整整一級而抵銷：

N ≈ λ / Δλ可見級數上限

三原光日光燈的紅線（611 nm）來自銪離子躍遷，頻寬只有 5–10 nm，紅玻璃紙擋掉綠、藍兩線之後剩下的就是這條窄線，N 可達數十級——參考解答數到 n = 45 正是靠這一點。換成白熾燈或白光 LED 配紅玻璃紙，透過的是 600–700 nm 一整片，Δλ ≈ 80 nm，N 掉到 8 級左右，接觸線外 5 mm 就什麼都沒有了。

為什麼一定要看反射光

玻璃—空氣界面的反射率只有約 4%。反射觀察時，兩道振幅相當的弱反射光互相干涉，背景又暗，可見度接近 1。透射觀察時，直接穿過的強光佔了絕大部分，被調制的部分不到十分之一，可見度只剩 0.08 上下——條紋確實存在，但淹沒在亮背景裡，眼睛分辨不出來。

本模擬對每個像素沿波長積分 I(λ) ∝ 1 − cos(4πd/λ)，再以 CIE 配色函數轉為 sRGB，因此白光下的彩色條紋、窄線光源下的高級數條紋、以及頻寬造成的褪色都是算出來的，不是畫上去的。
