實驗核心：為什麼沒有秤也能做

物理擺（複擺）以 P 點為軸做小角度擺動時，週期為

T = 2π IPM g d ，　IP = Im + M d2（平行軸定理）

題目給定兩個待測形式：圓環 Im = βM(R12+R22)、長條 Im = γML2。代入後把 M 約掉：

g T2 d4π2 = β(R12+R22) + d2　　│ g T2 d4π2 = γL2 + d2
質量 M 完全消失。這正是本題敢在「沒有秤」的條件下考轉動慣量的原因——你只需要量到「長度」與「時間」。而器材表中唯一能量時間的是碼錶，唯一能量長度的⋯⋯被監考老師收走了（注意事項 4）。所以本實驗真正的難點是：先用時間造出一把尺。

兩種取值方式

  1. 逐軸心計算（題目要求）：每個軸心量出 d 與 T，直接代入上式解出該軸心的 β 或 γ，最後對 ≥3 個軸心求平均值與標準差。
  2. 線性迴歸（推薦併用）：以 d2 為橫軸、gT2d/4π2 為縱軸作圖，理論斜率恆為 1、截距即 β(R12+R22) 或 γL2。
為什麼要兩種都做？設你的紙標尺有 δ 的比例誤差（例如長了 1%）。令 Y = gT2d/4π2，則逐軸心法解出的 β 相對誤差約為 −[Y/(Y−d2)]·δ：d 越大放大越兇，因為 β(R12+R22) 只有十幾 cm2，d2 一大就把它淹沒，等於用兩個大數相減去求一個小數。而迴歸截距求出的 β 只放大 約 1 倍，並且斜率偏離 1 的期望值就是 −δ（斜率本身有統計誤差，軸心數少、βS 又小時這個推估會很粗，要連同誤差棒一起看）。換句話說，迴歸不只比較準，還會順便告訴你校準做得好不好。分頁 ④⑤ 會即時顯示每個軸心的放大倍率，請據此挑選軸心。

原理：用時間造一把尺

單擺週期 T = 2π√(ℓ/g)，其中 ℓ 是懸點到擺錘質心的距離。但鐵球的半徑與掛鉤長度是未知的偏移量 δ，若直接用單一次量測，得到的是 ℓ = ℓ線 + δ，而你沒辦法在線上標出「球心」的位置。

解法是取兩個線長作差：在線上做 A、B 兩個記號，分別量週期，則

Δℓ = ℓB − ℓA = g (TB2 − TA2)4π2

偏移量 δ 在相減時完全消掉，而 Δℓ 正是線上 A、B 兩記號之間那一段的長度 — 一段長度已知的實體線段，這就是本實驗的標準器。

誤差策略：Δℓ 取得越長，相對誤差越小；但之後要把它標到 A3 紙條上，太長會放不下。計時一律以多個週期（建議 20 次以上）平均，把碼錶反應時間攤薄。擺角務必小於約 10°，否則 T ≈ T0(1 + θ02/16) 的大角度修正會造成系統性高估。
放手的同時就按下碼錶。按「釋放擺錘」會自動起算，模擬的就是這個動作。理由是：手動「起、停」兩次按鍵各帶一次反應誤差，合成後是單次的 √2 倍；放手與起算同步則只剩停錶那一次。本模擬如實反映這個差異——放手起算的計時雜訊為 0.09 s，擺動中途手動起算則為 0.13 s。若你想避開釋放瞬間的擾動而選擇中途起算，就要多計幾個週期把差距補回來。

量測方法：倍數放大法待答問題 1

你的紙標尺最小刻度約 —，直接拿去量金屬條的寬度（約 1 cm 量級）相對誤差會大到不可接受。實際考場的標準做法是把待測量「放大 n 倍」再除回去：

  • 圓周長：尼龍線沿銅環外緣（或內緣、或鐵桿）並排纏繞 n 圈，剪斷後拉直量總長 S，則 R = S/(2πn)。
  • 長度、寬度、厚度：把待測邊沿紙條連續比對 n 次（step-and-mark），量總長 S，則該邊長 = S/n。
n 不是越大越好：纏繞時的鬆緊、每次落筆的對位誤差會隨 n 累積，而讀數誤差則被 n 稀釋。此外總長不得超過標尺長度 Δℓ。自己試著找出最佳的 n。
繞線法有一個內建的系統誤差。線繞在環外緣時，線本身的中心線走的是半徑 R2 + （線徑/2）的圓；繞在內緣時則是 R1 − （線徑/2）。所以直接用 S/(2πn) 會把 R2 高估、把 R1 低估，各約半個線徑。這個偏差不會因為多量幾次而消失，而且它會讓 β 系統性偏低。想拿滿分的話，請設法量出線徑並修正（提示：把線並排纏繞 n 圈後量總寬度）。
為什麼要量鐵桿半徑 r？銅環直接掛在鐵桿上時，接觸點不是一個理想的刀口支點，環心到轉軸的距離是 R1 − r，而且環會在桿面上滾動而非純轉動（見分頁 ④）。沒有 r 就無法正確分析這個軸心。

兩種架設方式，兩套公式待答問題 2

甲、直接掛在鐵桿上（會滾動）

環心到桿心距離為 R1 − r。桿固定不動、接觸處摩擦足夠，因此環是滾動：環自轉角 ψ 與繞桿公轉角 φ 滿足 ψ = φ(R1−r)/R1。以能量法可得

T = 2π(R1−r)[1 + β(R12+R22)/R12]g

反解：β = R12R12+R22 [ gT24π2(R1−r) − 1 ]

乙、V 形尼龍線吊索（純轉動）

兩條線從桿上同一點連到環上兩個不同點，三角形三邊全被固定 → 整組繞頂點做剛體轉動，是乾淨的物理擺。線跨過圓桿時，一階近似的等效支點就落在桿的下緣切點，所以

d = s + R2　，　T = 2πβ(R12+R22) + d2g d

只要量出間距 s，再加上分頁 ③ 的 R2 就得到 d，不需要 r。

單條線吊掛是錯的。只用一條線打結掛上去，環仍能繞結點自轉，那是雙擺（兩個自由度），週期不服從上面任何一式。必須用兩條線或直接掛桿。

兩種架設方式，涵蓋 d 的兩側待答問題 4

甲、V 形尼龍線吊索（d > L/2）

膠帶把兩條線黏在條上兩點、同頂點吊起 → 剛體轉動。量出頂點到條上端的間距 s，則

d = s + L/2

乙、Ω 型金屬管夾（d < L/2）

管夾夾在距上端 a 處、夾環掛在鐵桿上，支點落在條身上，因此

d = L/2 − a

管夾本身有質量，但它幾乎就位在支點上，對週期的影響僅約 0.2%（質量在支點對 IP 無貢獻，只微幅拉近質心）。

兩式都服從同一條直線 gT2d/4π2 = γL2 + d2，所以兩種軸心可以混在同一張迴歸圖裡。這是金屬條比銅環好處理的地方（銅環直接掛桿是滾動，不能放進同一張圖）。
