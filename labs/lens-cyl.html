題目一：圓形透鏡的等效焦距與入射方向角 φ

在光軸上的物點（物距 xo）發出的光，經圓柱形透鏡兩次折射後回到光軸成像（像距 xi）。圓柱透鏡的兩個主平面都在圓心，所以本實驗的 xo、xi、f 一律由圓心量起，成像公式寫成

1/xo + 1/xi = 1/f　　⇒　f = xoxi / (xo + xi)

φ 是入射點的方向角：入射點半徑與光軸（物方）的夾角。光線在入射點的入射角 θi、折射角 θr 滿足 sin θi = n sin θr。

計算結果

(1) 入射光平行光軸：θi = φ

  1. Snell 定律：sin φ = n sin θr
  2. 入射點偏折 (φ − θr)；罐內弦與兩端半徑夾角相同（等腰三角形），出射點再偏折 (φ − θr)，總偏向角 δ = 2(φ − θr)。
  3. 出射光與出射點法線夾角也是 φ，所以出射光到圓心的垂直距離仍是 R sin φ。出射光與光軸夾角 δ，交光軸處到圓心的距離為
f = R sin φ / sin[2(φ − θr)]，　θr = sin⁻¹(sin φ / n)

近軸極限 φ → 0：f → nR / [2(n − 1)]，n = 1.33 時 f ≈ 2.02 R。φ 越大 f 越短 ─ 這就是球面（柱面）像差。

(2) 罐內光線平行光軸：θr = φ

  1. 弦與入射點半徑夾 θr，半徑與光軸夾 φ；θr = φ 表示罐內光線平行光軸，光路左右鏡像對稱 ⇒ xo = xi。
  2. sin θi = n sin φ；入射光與光軸夾角 α = θi − φ；由正弦定律，物點到圓心距離 xo = R sin θi / sin(θi − φ)。
  3. 代入 1/xo + 1/xi = 1/f 且 xo = xi：
f = xo/2 = nR sin φ / [2 sin(θi − φ)]，　θi = sin⁻¹(n sin φ)

須 n sin φ < 1（n = 1.33 時 φ < 48.8°）。近軸極限同樣趨近 nR/[2(n − 1)]。

兩種條件的比較（單位 R）

實驗上的關鍵：(1) 假設平行光（xo → ∞），但實驗桌上的螢光棒只在幾十公分外，同一個 φ 量到的 f 會隨 xo 改變，而且比 (1) 的預測偏短。把每個 φ 在不同物距量到的 f 對 R/xo 作圖，近似為直線，外插到 R/xo → 0 就得到平行光的 f∞，才能公平地和 (1) 比較（見第 ④、⑤ 頁）。

數據迴歸：f 對 R/xo

對每個 φ，以 u = R/xo 為橫軸、f/R 為縱軸作最小平方直線 f = f∞ + k·u。截距 f∞ 就是物體在無窮遠（平行光）時的等效焦距。旁邊並列「直接平均」的結果作對照。

σ 為迴歸標準誤差（需同一 φ 至少 3 個不同物距）。R² 越接近 1 表示直線模型越適用。
