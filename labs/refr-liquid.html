實驗情境：這是一張俯視圖

15 cm 直尺側立在壓克力槽中，刻度面朝向槽壁，加入液體使液面恰好切在刻度線高度的一半。每一條刻度線的上半段由液面上方的空氣傳光，下半段由液體傳光。眼睛在槽外隔著槽壁觀察時，下半段會相對上半段錯開。

觀察條件是：液面下的刻度 A（位置 X）看起來與液面上的刻度 B（位置 X+ΔX）對齊。這表示兩條光線以同一個方向進入眼睛：它們共用「眼睛 → 槽壁外側 → 穿過壁厚 → 槽壁內側」這一段，只在槽內才分成液體路徑與空氣路徑。

第 1 小題證明（不考慮壓克力）

令 θ₁ 為光在液體中與法線的夾角，θ₂ 為光在空氣中的折射角，R 為折射點與眼睛垂足的水平距離。

Snell 定律：n sin θ₁ = 1 · sin θ₂　⇒　n = sin θ₂sin θ₁

眼睛看到 B 的視線是直線，延長穿過液層：

tan θ₂ = Rd = X + ΔX − RD　⇒　R = d(X + ΔX)D + d，　X − R = DX − dΔXD + d
sin θ₂ = Rd² + R²　　sin θ₁ = X − RD² + (X − R)²

代入即得題目的關係式：

n = d(X+ΔX)(D+d)d² + (d(X+ΔX)D+d)² × (D+d)D² + (DX−dΔXD+d)²(DX − dΔX)

已逐步驗算：題目給的式子正確。

第 2 小題：考慮壓克力（壁厚 t，na = 1.49）

眼睛看出去的方向與法線夾 θ₃。穿入壓克力後偏折為 θ₂（sin θ₃ = 1.49 sin θ₂）。液體路徑在槽內為 θ₁（sin θ₃ = n sin θ₁），空氣路徑在槽內仍為 θ₃。

液體路徑：X = d tan θ₃ + t tan θ₂ + D tan θ₁
空氣路徑：X + ΔX = d tan θ₃ + t tan θ₂ + D tan θ₃

先由空氣路徑以數值方法（二分法）解出 θ₃，再由液體路徑得到 tan θ₁，最後 n = sin θ₃ / sin θ₁。

參考解答的疏漏：參考解答把空氣路徑寫成 X + ΔX − R = (D + 0.3) tan θ₃，等於假設空氣路徑直線穿過壓克力。但空氣路徑與液體路徑在壓克力內是同一段光，也必須偏折成 θ₂。兩者相差 t(tan θ₃ − tan θ₂)，以 t = 0.30 cm、θ₃ ≈ 30° 估算約 0.07 cm，與刻度對齊的判讀精度同一量級。上方表格可以看到它造成的 n 偏差。

觀察程序（依參考解答的步驟）

  1. 設定並量取眼睛到槽壁外側的距離 d。
  2. 左右移動頭部，使視野一中 0 刻度的上下兩半段切齊，此時眼睛正對 0 刻度。
  3. 選定刻度 A、B 並以油性筆標記（紅點 = A，在液面下；藍三角 = B，在直尺上緣）。
  4. 前後移動直尺（改變 D），直到視野二中液面下的 A 與液面上的 B 切齊，量取 D。
  5. 每組重複觀察 3 次取平均；改變 d 或 A、B 再做一組，共做至少 5 組。

數據整理

每一組數據（d、X、X+ΔX、D）以正確光路換算成一對 (sin θ₁, sin θ₃)。由 Snell 定律 sin θ₃ = n sin θ₁，以 sin θ₃ 對 sin θ₁ 作最小平方迴歸，斜率即為 n，截距應接近 0。

比起逐組算 n 再取平均，迴歸能利用所有數據決定一條最佳直線，並以截距檢查是否有系統誤差（例如眼睛沒對準 0 刻度）。

近軸近似的推導與限制

小角度時 sin θ ≈ tan θ ≈ θ，令 d′ = d + t/1.49（壓克力層等效的空氣厚度），兩條路徑變成：

液體路徑：X ≈ θ₃ (d′ + D/n)　　空氣路徑：X + ΔX ≈ θ₃ (d′ + D)

兩式相除消去 θ₃，整理成直線形式：

X(d′ + D) − (X+ΔX)d′ = 1n · (X+ΔX)D

以 (X+ΔX)D 為橫軸、左式為縱軸，斜率 = 1/n。這條線不需要解任何三角函數，計算很簡單，但它把所有角度都當成小角度。

本實驗的視角 θ₃ 常在 10°–30°。以 n = 1.40 為例，θ₃ ≈ 6° 時近軸法高估約 0.3%，≈ 18° 時高估約 2.5%，≈ 30° 時高估約 8%。角度越大，近軸線的 n 越偏高；大角度的數據點也會使近軸圖出現明顯的非線性。

1. 三種計算方式的比較（同一批數據）

把同一批量測數據分別以三種光路模型換算成 (sin θ₁, sin θ₃) 再做迴歸。此時還不知道真值，只能比較三者之間的差異。

參考解答的算法把空氣路徑畫成直線穿過壓克力，使推得的 sin θ₃ 偏小、sin θ₁ 偏大，因此 n 系統性偏低。忽略壓克力的第 1 小題公式反而只略微偏低，因為它把壓克力層當成空氣，只少算了 t(tan θ₃ − tan θ₂) 這一小段；參考解答則是液體路徑有算、空氣路徑沒算，兩條路徑不一致。
