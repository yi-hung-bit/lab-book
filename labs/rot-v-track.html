V 型軌道截面

關鍵幾何：有效滾動半徑

球心到轉軸距離 = 0，接觸點到轉軸的垂直距離： r_eff = r · sin α （α = 頂角的一半） 頂角 90° → r_eff = r·sin45° = r/√2 ≈ 0.707 r 平面 180° → r_eff = r·sin90° = r （退化為一般斜面）
這是本題最容易錯的地方。滾動條件是 v = ω·r_eff，不是 v = ωr。頂角 90° 時 ω 比平面斜面大 √2 倍，轉動動能變成兩倍：
mgh = ½mv² + ½Iω² = ½mv²(1 + β/sin²α) ，β ≡ I/mr² 頂角90°： mgh = ½mv²(1 + 2β) = ½mv² + βmv²
若誤用平面斜面的 (1+β)，第四部分整題會系統性偏掉。

真實效應開關

兩個真實失效模式的物理：
① 打滑（試題範圍內幾乎不會發生）：維持純滾動的條件是 tanθ ≤ μ·sinα·(1+β/sin²α)/β。V 槽有兩個接觸面，法向力總和被放大成 mg·cosθ/sinα，所以比平面斜面更不容易打滑。代入真實材料（鋼球／賽璐珞球對鋁軌，μ≈0.26–0.44），臨界角約落在 40°–47°——這正是試題把角度上限訂在 40° 的原因。想看到打滑，要把傾角拉到 45° 以上的探索區。打滑後轉動分配變少、球變快，該點會落到 h–v² 直線下方，使斜率偏小、截距變正。
② 空氣阻力（只對桌球顯著）：桌球約 2.7 g、半徑 2 cm，單位質量阻力是金屬球的 61 倍；終點附近阻力約佔淨驅動力的 11%。淨效果是讓塑膠球反推的 β 偏高約 3.5%（金屬球僅 +0.3%）。注意此時運動已不是等加速度，而題目要求的 v = 2d/t̄ 正是建立在等加速度假設上——這是誤差的真正來源。

原始數據

第二部分 (1)：質心速率 v

質心作等加速度運動、由靜止出發： 平均速率 = d / t̄ ，末速 v = 2d / t̄ （d = 1.000 m） 標準差傳遞： σ_v = 2d·σ_t / t̄² ， σ_(v²) = 2v·σ_v

第二部分 (2)：h–v² 關係圖與斜率

斜率單位為 s²/m（h 為 m、v² 為 m²/s²）。理論上截距應為 0；若截距明顯不為零，通常來自碼錶反應時間的系統性偏差。

第三部分 (1)：旋轉圈數 N 的推導

球在 V 槽中與兩斜面各接觸一點。 轉軸通過質心、垂直軌道與重力方向。 接觸點到轉軸的垂直距離（有效滾動半徑）： r_eff = r·sin α （2α = 軌道頂角） 頂角為直角 → r_eff = r/√2 純滾動（不滑動）：滾動距離 d 對應總轉角 φ = d / r_eff = √2·d / r N = φ/2π = ───────── = √2·d / (2πr) 2π·r/√2 球上距離轉軸最遠的點（距軸 r），相對質心的速率： v_max = ω·r = (v/r_eff)·r = √2·v

第三部分 (2)：游標尺量測球半徑（各 10 次）

游標尺夾量桌球時會輕微壓扁球殼，量到的直徑會略為偏小——這是真實實驗會發生的系統誤差，模擬中已納入。

各角度的圈數與最遠點速率

第四部分 (1)：減少的重力位能 ÷ 增加的質心平移動能

由斜率 k = h / v² ： ΔU/ΔK_平移 = mgh / (½mv²) = 2g·k = 1 + β/sin²α 頂角 90° → ΔU/ΔK = 1 + 2β 實心球 β=2/5 → 1.800 球殼 β=2/3 → 2.333
兩者不相等。減少的重力位能同時轉換成質心平移動能與繞質心的轉動動能；在 V 型軌道中 ω = v/(r·sinα) 比平面斜面大，轉動動能佔比再被放大，所以比值遠大於 1。

第四部分 (2)：兩球差異的來源

兩球比例不同，且與質量、半徑完全無關——只取決於無因次的轉動慣量係數 β = I/mr²。空心球殼質量集中在外緣（β=2/3），實心球質量分布較靠近轉軸（β=2/5），所以球殼把更大比例的位能存進轉動動能，滾到終點時質心較慢。

反推 β 與真值揭曉

β = (2g·k − 1)·sin²α （分析中取 g = 9.8 m/s²）
