測量與不確定度

四個小工具，練習有效數字判讀、不確定度計算、不確定度組合與因次分析 — 對應課本 Part 1–3。

輸入一個測量數值（可含小數點），程式會依教材規則標出「有效數字」與「可疑（估計）數字」。試試 40003、320、0.025、0.02500、2.51000。

不確定度計算機 PART 1

輸入重複測量值（逗號分隔）求 A 類不確定度，並輸入儀器最小刻度求 B 類不確定度，程式會依課本規則合成並取捨。

誤差 vs. 不確定度　「誤差」＝測量值－真值，是單一測量的偏差（真值通常未知）；「不確定度／不準量」則是測量值分布範圍的估計，恆為正值，用來宣稱真值可能落在的區間。

不確定度傳遞模擬 PART 2

輸入兩個受測量 X = x ± u_x 與 Y = y ± u_y，選擇運算方式，觀察不確定度如何組合。

課本例題：A4 紙張面積 長 (29.68 ± 0.13) cm、寬 (21.03 ± 0.11) cm 相乘 → 面積 ≈ (624.2 ± 4.3) cm²。點選上方「X × Y」並代入試試看。

乘方傳遞：Z = a·Xⁿ PART 2

單一受測量 X = x ± u_x 取乘方或倍率時，相對不確定度為 |σ_Z/Z| = |n|·(u_x/x)。試試課本例：r = (10.0 ± 0.3) cm 的圓面積 A = πr²（a = π, n = 2）。

指數傳遞：X = a·e^(bu) 師大講義

相對不確定度 σ_X/X = |b|·σ_u（σ_u 為 u 的絕對不確定度）。例：輻射強度衰減 N = N₀e^(-t/τ)，N₀=1000/s，τ=5days，t=20±0.042 days，此時 b = -1/τ = -0.2。

對數傳遞：X = a·ln(w) 師大講義

σ_X = |a|×(σ_u/u)，只與 u 的「相對不確定度」有關。例：輻射時間 t = -τ·ln(N/N₀)，τ=5，N=10±1（相對不確定度 10%），N₀=1000，此時 a = -τ、ln 內數值 w = N/N₀ = 0.01。

因次參考表 PART 3

「因次」表明物理量的成分，與單位選擇無關。以下為 SI 基本量的因次符號。

物理量因次物理量因次
長度[L]溫度[Θ]
質量[M]發光強度[J]
時間[T]物質量[N]
電流[I]角度（導出，無因次）1
範例：彈簧振動週期的因次分析 週期 P 與彈簧常數 k、質量 m、振幅 R 的關係設為 P = a·kxmyRz，a 為無因次常數。

[k] = [M][T]−2（力／長度）　　[P] = [T]

代入：[T] = ([M][T]−2)x[M]y[L]z
比對 M：x + y = 0　比對 T：−2x = 1　比對 L：z = 0
解得 x = −1/2, y = 1/2, z = 0　→　P = a√(m/k)，振幅 R 與週期無關。

最小平方法（線性回歸）師大講義

輸入成對的 x、y 數據（以逗號分隔，個數需相同），求最佳擬合直線 y = mx + b 及其斜率、截距的不確定度。對應公式 (14)(15)(29)(35)。

座標紙選用提醒 線性關係 y = mx+b 用直角座標紙；指數關係 y = a·e^(bx) 取對數後成直線，宜用半對數座標紙；乘方關係 y = a·xⁿ 取對數後成直線，宜用全對數座標紙，斜率即為 n。

單擺測重力加速度 · 虛擬實驗室
