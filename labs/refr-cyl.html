實驗任務

器材：透明圓柱、白線夾心圓柱（兩者透明部分材料相同）、游標尺（最小刻度 0.05 mm）、方木柱、標籤貼紙、直尺、方格紙等。

一、用游標尺量透明圓柱體積 V = πR²h。二、設計實驗量圓柱透鏡焦距。三、測量光在空氣中速率是在圓柱材料中速率的幾倍，即折射率 n = vair/vt。

視半徑法：n = B / b

觀察者在右方遠處，光線近似平行進入眼睛。把光線反向追跡回圓柱內：恰好擦過白線核心邊緣的那一條光線（紅色），出射後離軸的距離就是看到的視半徑 B。

核心邊緣切線在圓柱內與法線夾角 θr：sin θr = b/R；出射後與法線夾角 θi：sin θi = B/R。由 sin θi = n sin θr 得 B = nb，與 R 無關。

適用條件：nb < R。若 nb ≥ R，整個圓柱看起來都是白色，視半徑被圓柱外緣截斷為 R，此法失效。因此任何量到的 B 都不可能超過 R。

圓柱透鏡的焦距

圓柱（厚透鏡）兩主平面都通過圓心，近軸焦距由圓心量起：

f = nR / 2(n − 1)

圖中是精確光線追跡：離軸愈遠的邊緣光線聚焦愈靠近圓柱（球面像差），所以實際觀察到「影像翻轉」的位置會比近軸焦點稍近。由 f 可反推 n = 2f / (2f − R)，與視半徑法交叉驗證。

③ 圓柱透鏡焦距：影像翻轉法

把貼有標籤（紅點＋黑色箭頭）的方木柱放在透明圓柱後方，從前方透過圓柱觀察。方木柱由貼近圓柱開始往後移：距離小於焦距時看到正立放大虛像，大於焦距時看到左右顛倒的實像，在焦距附近影像極度放大、模糊不清。記錄「不成像區間」的兩端，取中點為 f。

圓柱只在水平方向聚焦，所以影像只有左右放大或翻轉，上下不變。兩側沒被圓柱擋住的標籤可以當作正立參考。

為什麼還要讀「外緣」？

眼睛在有限距離 L 時，看到的圓柱外緣寬度 W 和核心寬度都被同樣的比例壓縮：W/2 ≈ R′√[(L−R′)/(L+R′)]。L = 30 cm 時約縮 3%，直接用 B/b 會系統性偏低。這個壓縮對核心與外緣幾乎相同，所以用比值 B = (wB/wW)·D′/2 就能把視差消去。第 ⑤ 頁會兩種算法並列。

觀念整理

觀察距離修正：眼睛不在無窮遠，影像翻轉的條件是「實像正好成在眼睛上」，不是「像在無窮遠」。由 1/d + 1/L = 1/f 得 f = dL/(d+L)，翻轉點會比 f 遠一點。

球面像差：離軸愈遠的光線焦距愈短，翻轉區的近端由邊緣光線決定，所以不成像區間會往內延伸，中點偏短。

這兩個效應方向相反，但通常像差較大，所以焦距法求出的 n 常偏大；視半徑法用的是單一條切線光線，沒有像差問題，較準確。
